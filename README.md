# Skills

Персональные скиллы для AI-агентов. Каждый скилл — отдельный каталог с файлом `SKILL.md` (фронтматтер `name` / `description` + инструкции) и вспомогательными шаблонами в `templates/`.

## Список скиллов

| Скилл | Описание | Когда срабатывает |
|---|---|---|
| [`adr`](adr/SKILL.md) | Пишет и сопровождает Architecture Decision Records в `docs/adr/`. Если ADR в проекте ещё нет — разворачивает инфраструктуру: каталог, индекс, ADR 0001 о принятии практики, правило для агентов в `AGENTS.md`. Выбирает номер и slug, заполняет каноническую структуру, помечает заменённые и уточнённые ADR без переписывания принятых, обновляет индекс `docs/adr/README.md`. | Просьба написать или обновить ADR; изменения, вводящие новую модель данных, меняющие публичный API или контракт, добавляющие интеграцию, меняющие подход или вендора, вводящие инварианты конкурентности или транзакций, отказ от фичи. |
| [`plan`](plan/SKILL.md) | Составляет план реализации до написания кода и ведёт его до завершения. Пишет план в `.plans/<slug>.md` (цель, скоуп, шаги по фазам с конкретными файлами, проверки, риски), открывает на ревью и жёстко останавливается до явного одобрения; после одобрения выполняет шаги по порядку, отмечая чекбоксы, статус и итоги прогонов. | Явная просьба составить план («сделай план», «распланируй», «plan this out»), пересмотреть или продолжить существующий план. |

## Установка

### GitHub CLI (`gh skill`)

```sh
# Выбрать скиллы интерактивно
gh skill install pokidovea/skills

# Установить конкретный скилл глобально (для всех проектов)
gh skill install pokidovea/skills adr --scope user

# Установить все скиллы
gh skill install pokidovea/skills --all --scope user

# Обновить установленные скиллы
gh skill update --all
```

Целевой агент задаётся флагом `--agent` (например, `--agent claude-code`), по умолчанию скилл ставится на уровне проекта (`--scope project`).

### `npx skills`

```sh
# Выбрать скиллы интерактивно
npx skills add pokidovea/skills

# Установить конкретный скилл глобально (для всех проектов)
npx skills add pokidovea/skills --skill adr -g

# Посмотреть список скиллов без установки
npx skills add pokidovea/skills -l

# Обновить установленные скиллы
npx skills update
```

Целевой агент задаётся флагом `--agent` (например, `--agent claude-code`), без `-g` скилл ставится на уровне проекта.
