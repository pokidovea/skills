# Architecture Decision Records (ADR)

Индекс решений по эволюции проекта. Всего ADR: **N**, сверено с кодом **YYYY-MM-DD**. Суть ниже описывает решение на момент принятия, а не обязательно текущее поведение; последующие замены и уточнения указаны отдельно. Текущее поведение системы описано в остальных документах `docs/`.

Принятые ADR не переписываются. Замена решения — новый ADR, у старого меняется только статус. Мелкие исправления после выкатки — раздел `## Коррекция YYYY-MM-DD` в конце ADR.
